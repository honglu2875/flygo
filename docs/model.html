01 / The biological constraint

The wiring is data.
The computation is a model.

Broadcast through sensory cells

Flatten the 12 feature planes into 972 numbers. A balanced seeded permutation assigns one feature to each annotated sensory cell, so each feature drives roughly 16–17 cells. Its learned gain scales the injected current.

Pictures use the validation position below. History is relative to the current player. Black-to-play, signed komi/area and consecutive passes divided by two are broadcast planes. The Rust engine separately retains the full rules history.

out

Pool through nonsensory cells

Each nonsensory neuron belongs to one balanced group. Learn a gain ρ for each neuron, sum its rectified activity, and normalize by the square root of the group size.

zg = Σi∈g ρi ReLU(hiK) / √|g|

The 2,624-group variant subdivides each of the 656 baseline groups four ways. This schematic shows four parent groups. The fly graph itself is identical.

Policy: linear map to 81 intersections + pass, then an exact legal-action mask and softmax.
Value: linear map followed by tanh, from the player-to-move perspective.

Sensory and readout sets are disjoint. Every board signal reaching a head must travel through the graph; there is no direct board-to-head bypass. Assignments are task-defined, not a claim that fly sensory cells have a natural Go-board representation.

04 / Inside the recurrent cell

Sparse messages.
Nonlinear state updates.

The baseline is a leaky rate network. Each pass combines a sparse matrix multiplication with elementwise operations. Unrolling the same cell K times gives a nonlinear, shared-weight computation graph.

rk = ReLU(hk)
hk+1 = (1 − α) ⊙ hk + α ⊙ (W rk + b + I(x))

h holds one scalar state per neuron and position; r is the outgoing activity. W holds weights on existing edges, b is a type-shared bias, I(x) is the board current, and ⊙ means elementwise multiplication.

Depth happens inside one evaluation

Same W, bias, leak and input at every pass. Select K = 8 above to unfold four more steps.

α controls mixing with the old state. A smaller α changes activity more slowly. We learn it per cell type using α = 0.01 + 0.98·sigmoid(ℓ); it starts at 0.5. The demo uses a single α for clarity.

Internal passes are not biological seconds. We have not calibrated the step size to physical time. More passes can extend communication along graph paths, but do not guarantee stability, long memory or better predictions.

The demo uses a 12-node illustrative circuit and the actual update form. It is not a visualization of measured or full-model fly activity.

Current model: reset for each board

Initialize h⁰ = 0.01 → perform K passes → read policy/value. On the next board evaluation, reset again. Gradients run through these internal passes. Four board-history frames provide explicit temporal context.

A future option: memory across moves

Carry a state between actual moves and train across longer sequences. This requires an explicit memory contract: reset rules, truncated training, and separate state copies for hypothetical search branches.

Related precedent: Lappalainen et al., Nature (2024) optimized a connectome-constrained recurrent fly visual-system model for optic flow. That work motivates task optimization of constrained dynamics; it does not establish that the MaleCNS graph is a good Go architecture.

New / A controlled neuron extension

Soften the threshold.
Keep the same connections.

A hard ReLU has zero sensitivity below its threshold. The experimental smooth rule retains a graded response near zero. Its scale is fixed configuration, with no extra learned parameters.

One scalar rule, two implementations

rs(h) = s · log(1 + exp(h / s))
drs/dh = sigmoid(h / s)

Use the same function in recurrent messages and final pooling. The leaky update, all neurons, all existing edges and parameter shapes stay fixed. The hard baseline uses s = 0 as a separate exact branch.

This is also the expected ReLU response under logistic threshold noise. The implementation computes that expectation deterministically; it does not draw noise samples. Very negative rates can still underflow to zero in FP32.

What we test: s = 0.01 or 0.05, crossed with two declared optimizer choices, at 32,000 exposures. The complete screen selects s = 0.01 with the bias-scaled optimizer for a three-seed, 128,000-exposure confirmation. Full-state derivatives, three updates and fresh CPU continuation pass. Actual smooth-rate TPU qualification is a separate next gate.

At 128,000 exposures, the selected rule improves policy KL in all three seeds, by 0.0269 on average. The mean value change remains unresolved. 06 / The next design space

Richer cells.
The same allowed wiring.

Change one mechanism at a time. Sensory and visual-output adapters are under controlled study. Smooth firing rates are CPU-qualified; local adaptation and dynamic gates remain proposals. Each keeps inter-neuron communication on the fixed edge set.

Extension space

Give the sensory interface more structure

Replace the seeded assignment with a controlled, type-aware or task-structured projection into the same sensory cells. Any spatial correspondence must be explicitly inferred or designed.

I(x) = Psensory(x);   Inon-sensory = 0

Question: does a better attachment make the fixed graph easier to use? Keep the adapter budget small and prevent a board-to-head bypass.

Further out

Compartments & delays

Multiple states per neuron, or delay classes on existing connections, can enrich temporal processing. Specify the extra state and sparse passes before allocating a run.

Cost: more node state; delay history and potentially more sparse operations.

Further out

Fast plasticity & noise

Episode-local strength changes, release noise, adaptation and slow consolidation are possible mechanisms. Separate those states from parameters learned across the dataset.

Cost: one FP32 fast variable per edge and batch element already costs about 1.95 GB at batch 32.

Further out

Memory across moves

Carry neural state over a trajectory. A hypothetical search branch needs its own state: exploring one variation must not mutate the real game’s memory.

Cost: branch-state copies, longer training sequences, explicit truncation and reset rules.

“Routing” means changing the gain of existing paths. A learned global controller that reads every neuron and broadcasts back would create additional communication routes, so it does not satisfy our strict fixed-topology experiment.
Write equations + state contract→Rust forward + backward→JAX parity + cost check→Controlled learning study

Biological inspiration is a hypothesis, not a default implementation. For example, Cohn et al., Cell (2015) studied compartmentalized neuromodulation in the fly. Our proposed local gates are an engineering abstraction, not a reproduction of that circuit.

Learn a prior.
Search can improve it.

The current study is offline teacher distillation. Search is a separate layer around policy/value inference. Later, improved search targets can become the next training signal.

A strong 9×9 expert plays either color against varied KataGo checkpoints. The fixed teacher labels every pre-action state for both players with raw policy and value.

PUCT / Gumbel

A leaf board goes through the same input → K-pass fly → readout pipeline. Search combines priors with explored outcomes. Its simulation budget is separate from internal neural depth.

K passes per evaluation × neural evaluations per search

For one root evaluation plus S evaluated leaves, about K(S + 1) graph passes. Terminal leaves, caching and batching affect the actual work.

What comes after the offline screen

Compare priors first, then use matched search budgets against KataGo checkpoints. Online refinement can generate stronger search policies and improved value targets, and distill them back into the network.

08 / Practical computation

Vectorize the batch.
Keep the graph sparse.

For B positions, store neuron activity as N × B. One pass costs O(E·B); K passes cost O(K·E·B). The memory layout and sparse kernel determine whether hardware can use that structure efficiently.

Implemented + CPU qualified

Rust owns the production path.

Destination-ordered CSR gathers source activity and accumulates directly into a destination row across the batch. The transpose supports backward propagation. Native gradients and Adam train the complete model.

We avoid materializing one message vector for every edge. Dense policy/value heads are small relative to the recurrent graph.

Four-host TPU learner qualified

Replicate the graph. Shard the batch.

The qualified JAX path runs on all four hosts and 16 TPU devices. Degree buckets and bounded gather tiles implement the same graph, with an explicit transpose and edge-gradient rule.

At global batch 2,048, measured kernels deliver 754 inference and 577 training positions/s; the complete fly learner delivers about 517 training positions/s including validation and checkpoints. Fresh-process recovery reproduces the next updates exactly.
